# Images Folder

Place your company and client logos in this folder.

## Required Images:

1. **jubilant-logo.png** - Logo for Jubilant Agri & Consumer Product Ltd
   - Recommended size: 200x100px or similar aspect ratio
   - Format: PNG with transparent background (preferred)

2. **insilco-logo.png** - Logo for Insilco Limited
   - Recommended size: 200x100px or similar aspect ratio
   - Format: PNG with transparent background (preferred)

## How to Add Logos:

1. Download or obtain the logos from the companies
2. Save them with the exact filenames:
   - `jubilant-logo.png`
   - `insilco-logo.png`
3. Place them in this `images` folder
4. The website will automatically display them

## Note:

If logos are not found, the website will show a placeholder with the company initials.
Make sure the logo files are in PNG, JPG, or SVG format for best compatibility.
